# 🎬 YouTube Main Page Clone (Quasar Framework)

A responsive clone of YouTube’s main interface built using the [Quasar Framework](https://quasar.dev/) and Vue.js. This project replicates YouTube's main layout, sidebar, and video grid using modern front-end tools.

## 📸 Preview

![screenshot](./preview.png) <!-- Add a screenshot if you have one -->

## 🚀 Features

- 📱 **Responsive Design** — Works across desktop, tablet, and mobile devices.
- 🧩 **Sidebar Navigation** — Expandable/collapsible sidebar similar to YouTube.
- 🎥 **Video Grid Layout** — Flexible video thumbnails using Quasar’s grid system.
- 🌗 **Dark/Light Theme Ready** — Built with Quasar’s theme system in mind.
- ⚙️ **Component-Based Architecture** — Clean, reusable components using Vue.js.

## 🛠 Tech Stack

- [Vue.js (Options API)](https://vuejs.org/)
- [Quasar Framework](https://quasar.dev/)
- [SCSS](https://sass-lang.com/) for styling
